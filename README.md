# System Monitor

Лёгкий системный монитор в духе HWiNFO — только без тяжести, телеметрии и
лишнего. Полностью офлайн: приложение ничего никуда не отправляет.

_A lightweight HWiNFO-style system monitor. Fully offline, zero telemetry._

## Что показывает

- **Процессор** — общая загрузка, загрузка по ядрам, модель CPU, график за минуту
- **Память** — RAM (использовано / всего) с графиком, файл подкачки
- **Диски** — объём и заполненность каждого диска
- **Температуры** — датчики, которые отдаёт система (см. ограничения ниже)
- **Видеокарта** — название (на Windows определяется через WMI)
- **Система** — версия ОС, имя компьютера, аптайм

Обновление — раз в секунду.

## Стек

- **Rust** + [sysinfo](https://crates.io/crates/sysinfo) — сбор данных
- **Tauri 2** — нативная обёртка: итоговый установщик весит мегабайты, а не
  сотни мегабайт, как у Electron
- **HTML/CSS/JS** без сборщиков и фреймворков — интерфейс, графики рисуются
  на обычном `<canvas>`, поэтому не нужен даже Chart.js и интернет

## Честные ограничения v0.1

- **Температуры на Windows**: `sysinfo` видит далеко не все датчики, а без
  прав администратора может не увидеть ни одного. Полноценные сенсоры —
  следующий шаг (интеграция LibreHardwareMonitor).
- **Видеокарта**: в v0.1 показывается только название, без загрузки и
  температуры GPU.
- Первая секунда после запуска: загрузка CPU может показать 0% — `sysinfo`
  считает процент по разнице между двумя замерами.

## Скачать готовую сборку

Сборка под Windows делается автоматически в GitHub Actions при каждом пуше:
вкладка **Actions** → последний запуск **Build** → артефакт
`system-monitor-windows` (внутри `.msi`, `.exe`-установщик NSIS и портативный
`system-monitor.exe`).

## Собрать самому

Нужны Rust (stable) и Node.js 18+.

```bash
npm install
npm run icons   # сгенерировать иконки (они не хранятся в репозитории)
npm run build   # готовый установщик в src-tauri/target/release/bundle/
npm run dev     # режим разработки
```
